# 提示词工程守则（Mausritter 战役生成器）

适用于所有对战役生成器提示词（`战役生成器/` 下各层级模块，当前含 `冒险地点层/00-05`）的优化任务。本守则随任务自动加载，违反任意一条视为未完成。

## 1. 不撤回已有修改

- 优化前必须 Read 当前文件全文，确认哪些段落是历史优化成果或用户手改
- 只修改目标缺陷相关的段落，不动无关内容
- 禁止整段重写、禁止"顺手"调整无关措辞、格式、编号
- 若目标段落与既有内容冲突，先指出冲突点，不擅自删改

## 2. 泛化原则

- 提示词必须适用于所有战役，禁止引用单个冒险模组的专有设定（地名、物品名、角色名、房间陈设）作为规则约束或示例
- 修复证据可以用模组名指代（如"偏移学院"），但规则表述必须通用
- 禁止为单次战役打专项补丁

## 3. 修改粒度

- 一次只修一个缺陷（对照 `06_验收标准与战役基线.md` 的 D-编号），不顺手重构
- 每处修改注明对应的 D 编号
- 涉及多文件时，先列出修改计划再动手

## 4. 善用 Skill

- 涉及朗读文本、导入等叙事文本的规则更新，必须考虑 humanizer-zh 去AI化流程的衔接
- 涉及提示词结构、写法评估时，可用 writing-skills 校验
- 按主提示词流程生成模组正文时，朗读文本与导入段落调用 humanizer-zh 去AI化

## 5. 验收

- 每次优化完成后，对照 `06_验收标准与战役基线.md` 的验收口径（"不再出现/抽查通过"）说明结果
- 修改提示词后，条件允许时用新提示词试生成验证
