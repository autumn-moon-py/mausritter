# 子模块：导入与背景生成器

## 功能

为GM已经指定的冒险地点生成一段简短、适合直接朗读的玩家导入和背景以及GM备注。导入要让玩家知道为什么这次要去那里、那里有什么值得在意的事，以及出发前选择路线时需要留意什么；不把是否前往写成玩家需要重新决定的事项。

## 输入

- 冒险地点名称与主题
- 衰败原因
- 居民类型与目标
- 核心秘密

若有可用的公开战役上下文，只能接收定居点公开传闻、地点公开状态、已公开的势力活动、最近公开变化和玩家已知的未完成事项。禁止接收或写入房间布局、陷阱解法、唯一宝藏、未发现的NPC动机与核心秘密。

## 处理流程

### 1. 确定西征钩子

玩家已经知道本次要去哪个地点。先从冒险地点的主题、居民、现状和核心秘密中提炼一组相互关联但不泄露真相的导入材料。开始组织导入前，先确定一个该地点自己的叙事发动机：是什么正在推动局势变化，并且会让这次出发显得值得。发动机可以来自正在扩大的异常、即将错失的资源或交易、移动中的目标、进行中的冲突、即将发生的环境变化、某个关系或承诺的破裂，或其他符合地点主题的具体动力。不要默认使用酒馆传闻、NPC委托或“发现异常后前往”的顺序。

钩子必须保留以下信息功能：

- 定居点现场：日常生活中出现了什么变化
- 具体来源：谁亲眼见过或亲身受到影响，他与地点有什么关系
- 可确认事实：玩家可以暂时相信什么
- 未解缺口：哪件事仍无法解释
- 当前变化：谁正在做什么，何时可能发生下一步，或不介入会失去什么

导入不需要设计多个玩家目标，也不需要让玩家重新决定是否前往。只需让玩家理解地点的吸引力、风险和当前变化，并为出发前的路线选择提供有用信息，例如哪条路更快、哪条路可能遇到什么、哪种风险值得绕路，或为什么应该尽快出发。

信息必须具体可感知，指向冒险地点，并隐晦暗示其危险或价值。它可以来自传闻、物证、异常变化、交易、争执、返回者报告、玩家此前行动的后果或其他合理来源，不要求每次都经过NPC口述。回填一致性由战役层组装步骤核对，本层不接收战役层流言。

这些信息共同构成地点钩子，收纳于冒险地点文件内部（导入）。GM可将其作为正在发生的行动、被带回定居点的物证、失败的交易、受影响者的日常反应、追踪目标留下的痕迹、即将到来的变化、两方争执或其他自然场面呈现，展示场景不限于告示板。不要把它们写成传闻清单；让地点自己的动力决定信息如何出现。

若导入中需要NPC作为线索来源，必须写出他与地点的关系、一个正在进行的生活动作、一个独立欲望，以及一个不愿说出的事实或偏见。NPC细节直接融入朗读文本与背景叙述，不单独列数据表。NPC可以请求帮助，但不能替玩家指定唯一目标；玩家拒绝或延迟后，NPC应有自己的反应或行动。

**NPC形象塑造**（自由发挥，无需掷骰）：以下素材仅作启发，可自由组合、合理改造或自创，不必受限于所列项，组合合理自洽即可：

- 社会地位：贫穷、平民、市民鼠、公会鼠、贵族鼠
- 外貌：深情的眼睛、鲜艳的补丁衣服、雏菊花环、脏兮兮的衣服、大软帽、口袋里装满种子、弯曲的树枝手杖、携带生锈的别针剑、长而狂野的毛皮、非常非常老、缠着绷带的尾巴、尾巴系着蝴蝶结、缺一只耳朵、长胡须、闪烁的眼睛、巨大沉重的黑色斗篷、旧的战斗伤疤、非常年轻、剃过的毛皮、编织的毛皮
- 怪癖：不断梳理毛发、对天气着迷、精力非常充沛、见多识广、被巫师诅咒、容易受惊、为过去的罪行感到羞愧、非常好胜、浮夸的酒鬼、极其礼貌、毫无保留地诚实、缓慢谨慎的言辞、快速不规律的言辞、猫的秘密仆人、被老鼠养大、被家乡驱逐、养了很多宠物昆虫、讨厌户外、当地英雄、非常抽动的胡须
- 想要：自由、安全、逃离、刺激、权力、意义、健康、财富、保护、爱、食物、友谊、休息、知识、野蛮、美丽、复仇、效力、乐趣
- 关系：父母、兄弟姐妹、表亲、堂亲、祖父母、有亲属关系但不知道、已婚、前恋人、单相思、酒友、欠债、漫长而动荡的、死敌、公会兄弟、童年朋友、一个偷了另一个的东西、一起工作过、一起长大、效忠同一个领主、从未见过面

### 2. 生成玩家朗读文本

玩家朗读文本是GM在会话开始时直接读给玩家的内容。先朗读，后展开冒险。

**格式要求**：
- 不使用引用块（>），但允许使用单行注释式补充（如"她给人磨了一星期谷子挣的"）增强叙事节奏
- 朗读文本以1-2个短段为宜；只有地点信息确实需要时才增加长度，不为覆盖字段堆句子
- 必须自然涵盖：地点为何值得前往、一个可感知的现场或来源、一个值得留意的风险或变化；其余背景信息按需要放入`##背景`，不要为了凑齐字段全部塞进朗读文本
- 不必按固定顺序排列，不要把五项写成标题或检查清单
- 全部使用第二人称（"你们"）
- 若冒险涉及待寻对象（失踪、被绑、需营救的NPC），朗读文本必须描述其可识别特征（外观标记、行为特征、身份呼应），且该特征必须在后续具体房间的朗读文本中再次出现，玩家凭朗读文本即可在房间里认出目标，禁止只靠GM引用块点破身份
- 不出现玩家朗读之外的任何背景细节——历史、衰败原因、秘密等全部放到GM备注中

**边界规则**：
- 玩家朗读只描述所见所闻与动机，不写规则性内容
- **D-14默认所见所闻驱动**：GM已经指定冒险地点，玩家朗读文本负责说明为什么这次值得前往，以及出发前需要考虑的风险和路线，不把“是否前往”交给玩家重新决定。不出现固定酬金或任务条款；报酬可以来自地点本身，但不得成为唯一吸引力。导入不要求列出多个任务目标，不写“去不去由你们决定”或类似收束句式
- **允许少数冒险采用委托制**：若主题与场景明显需要（如"贵族鼠的乡间庄园"附近发生绑架事件），可在背景中提及相关 NPC 主动求助，但朗读文本仍以所见所闻为主，不写酬金金额与任务条款
- 玩家朗读不出现怪物弱点、伤害值、豁免类型等机制内容

**组织方式**：

先围绕已确定的叙事发动机，选择最自然的切入口，用最少的句子组织适合直接朗读的开场。切入口可以是正在发生的行动、被带回定居点的物证、一次失败的交易、受影响者的日常反应、追踪目标留下的痕迹、即将到来的变化、两方争执，或其他能让玩家立即看到局势正在运转的场面。正文优先保留一个有画面的细节和一个会影响路径选择的风险，删除不影响出发判断的解释、重复传闻和抽象悬念。

西征信息功能应在朗读文本和背景之间完整覆盖，但不要求全部塞进朗读文本，也不要求按照固定顺序出现。一个具体细节可以同时说明地点价值和风险；如果玩家需要知道更多，再由GM根据`##背景`补充。朗读文本不安排多个任务目标，只让玩家在前往指定地点前知道该留意什么、为什么路径选择有差别。

### 3. 生成背景与GM备注

GM信息分两个二级章节，放在玩家朗读文本之后：`## 背景`（可揭露）与 `## GM备注`（绝密）。

**`## 背景`（可揭露）必须包含**：
- 冒险地点的历史（建造、衰败、现状）
- 居民情况（类型、数量、行为模式）
- 线索来源（流言由谁散布、现象的真实成因、相关NPC与玩家的过往）
- 冒险原因（为什么现在需要冒险）

**`## GM备注`（绝密）必须包含**：
- 核心秘密的详细解释
- 关键NPC的隐藏态度和可能的反应
- 与其他房间或地点的秘密关联

**格式要求**：
- 不使用引用块
- 直接在各章节标题下用连贯段落叙述
- 信息完整，GM无需二次加工

**信息分层**：导入内容分两个章节，可揭露与绝密分开存放，不重复叙述，GM一眼可辨哪些能讲给玩家：

- `## 背景`：只放可揭露信息，GM参考使用，玩家询问或搜索时可自然透露。包括历史背景、居民日常行为、可观察的现状、线索来源
- `## GM备注`：只放绝密信息，玩家必须主动发现才能揭露。包括核心秘密的真相、NPC隐藏动机；机制规则仍放房间###机制章节和宝藏表GM备注列，不在GM备注重复

可揭露信息不得伪装成绝密藏进GM备注，绝密信息不得出现在朗读文本和背景中
- 文件开头的封面/主题简介语（标题下的一两句话）属于公开信息，不得提前点破GM备注中的绝密信息（核心秘密、隐藏真相、地点内部的关键设定）。封面语只呈现表面现象与悬念

**GM备注禁止项**（绝对不能写在GM备注里）：
- 怪物弱点描述（什么能伤害它）
- 具体伤害值和豁免类型
- 机制规则（陷阱如何触发、宝藏如何使用）
- 房间内部的规则性描述（光源、检定频次等）

**正确做法**：机制性内容统一放在居民数据章节的引用块里、房间的###机制章节、宝藏表的GM备注列。GM备注只说"故事"，不说"规则"。

### 4. 西征钩子自检

生成后逐项检查：

**说明**：
- 导入是否从定居点的具体生活变化开始
- 每条重要消息是否有来源、立场或可信度依据
- 玩家能否分辨哪些是事实、哪些仍是传闻
- 地点内是否有势力正在行动，而不是等待玩家
- 地点是否正在发生变化，是否有出发时机或路径风险值得玩家留意
- 是否让玩家明白为什么要前往指定地点，并能据此选择路径或准备方式
- 是否存在物质价值以外的关系、安全、认知或道德价值
- NPC是否有自己的欲望，而不只是发布任务
- 是否没有泄露房间、机制、唯一宝藏或核心秘密
- 是否没有宣传性形容词、空泛神秘感、整齐三段式和抽象结论
- 是否避免连续使用相同的开场场景、证人安排、段落顺序和收束句式
- 是否让玩家直接观察、判断或回应某件事，而不是始终旁听NPC转述

## 输出格式

```markdown
# 导入

[玩家朗读文本]

## 背景

[可揭露信息：历史背景、居民行为、线索来源，GM可自然透露]

## GM备注

[绝密信息：核心秘密真相、线索背后的原因，玩家主动发现才能揭露]
```

**示例说明**：

不提供固定剧情示例。若发动机是扩大的异常，可以从定居点受到的直接影响开始；若发动机是移动中的目标，可以从物证、追踪痕迹或返回者报告开始；若发动机是交易或资源窗口，可以从价格变化、缺货、争执或即将失效的机会开始；若发动机是派系冲突，可以从双方行动在定居点造成的不同后果开始；若发动机是关系或承诺即将破裂，可以从相关者的行动、隐瞒或矛盾说法开始。这些只是可选入口，不是固定分类。无论采用哪种入口，都必须回填五项信息功能、时间窗口或不介入后果，以及至少两个玩家目标方向。

```markdown
# 导入

[根据地点自己的叙事发动机组织朗读文本，不套用固定场景、证人数量、段落数量或信息顺序]

## 背景

[可揭露信息：历史背景、居民行为、线索来源]

## GM备注

[绝密信息：核心秘密真相、线索背后的原因]
```
