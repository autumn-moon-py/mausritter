# 子模块：导入与背景生成器

## 功能

为冒险地点生成玩家朗读文本和GM背景备注，让玩家获得冒险动机，GM掌握完整背景。

## 输入

- 冒险地点名称与主题
- 衰败原因
- 居民类型与目标
- 核心秘密

## 处理流程

### 2. 生成玩家朗读文本

玩家朗读文本是GM在会话开始时直接读给玩家的内容。先朗读，后展开冒险。

**格式要求**：
- 不使用引用块（>），但允许使用单行注释式补充（如"她给人磨了一星期谷子挣的"）增强叙事节奏
- 每句单独一段，简洁短句，便于GM朗读
- 推荐涵盖四类信息：委托人身份与外观 / 委托人状态或性格 / 求助原因与目标 / 报酬与请求
- 不必严格按四句对应，GM 可根据叙事自然合并或拆分
- 全部使用第二人称（"你们"）
- 若冒险涉及待寻对象（失踪、被绑、需营救的NPC），朗读文本必须描述其可识别特征（外观标记、行为特征、身份呼应），且该特征必须在后续具体房间的朗读文本中再次出现，玩家凭朗读文本即可在房间里认出目标，禁止只靠GM引用块点破身份
- 不出现玩家朗读之外的任何背景细节——历史、衰败原因、秘密等全部放到GM备注中

**边界规则**：
- 玩家朗读只描述动机、外观、酬金，不写规则性内容
- 酬金只在玩家朗读文本中写一次，GM备注不重复酬金数字
- 玩家朗读不出现怪物弱点、伤害值、豁免类型等机制内容

**模板**（顺序可调）：

[委托人身份+关系]曾[关系描述]，他/她[直观外观印象]

[这位委托人][状态/性格细节]

[求助原因：具体的、可感知的异常或目标]

[报酬金额]，求你们去看看

> GM 可视叙事需要合并或拆分上述四类，不必逐句对应

### 3. 生成背景与GM备注

GM信息分两个二级章节，放在玩家朗读文本之后：`## 背景`（可揭露）与 `## GM备注`（绝密）。

**`## 背景`（可揭露）必须包含**：
- 冒险地点的历史（建造、衰败、现状）
- 居民情况（类型、数量、行为模式）
- 委托人信息（姓名、身份、与玩家的过往、动机）
- 冒险原因（为什么现在需要冒险）

**`## GM备注`（绝密）必须包含**：
- 核心秘密的详细解释
- 关键NPC的隐藏态度和可能的反应
- 与其他房间或地点的秘密关联

**格式要求**：
- 不使用引用块
- 直接在各章节标题下用连贯段落叙述
- 信息完整，GM无需二次加工

**信息分层**：导入内容分两个章节，可揭露与绝密分开存放，不重复叙述，GM一眼可辨哪些能讲给玩家：

- `## 背景`：只放可揭露信息，GM参考使用，玩家询问或搜索时可自然透露。包括历史背景、居民日常行为、可观察的现状、委托人过去
- `## GM备注`：只放绝密信息，玩家必须主动发现才能揭露。包括核心秘密的真相、NPC隐藏动机；机制规则仍放房间###机制章节和宝藏表GM备注列，不在GM备注重复

可揭露信息不得伪装成绝密藏进GM备注，绝密信息不得出现在朗读文本和背景中
- 文件开头的封面/主题简介语（标题下的一两句话）属于公开信息，不得提前点破GM备注中的绝密信息（核心秘密、隐藏真相、地点内部的关键设定）。封面语只呈现表面现象与悬念

**GM备注禁止项**（绝对不能写在GM备注里）：
- 怪物弱点描述（什么能伤害它）
- 具体伤害值和豁免类型
- 机制规则（陷阱如何触发、宝藏如何使用）
- 重复的酬金数字（已在玩家朗读出现）
- 房间内部的规则性描述（光源、检定频次等）

**正确做法**：机制性内容统一放在居民数据章节的引用块里、房间的###机制章节、宝藏表的GM备注列。GM备注只说"故事"，不说"规则"。

### 4. 简化钩子

钩子简化为"委托人发钱"，不需要复杂的钩子表。

**说明**：
- 委托人提供报酬
- 冒险原因在GM背景备注中交代
- 玩家朗读文本直接呈现冒险动机

## 输出格式

```markdown
# 导入

[玩家朗读文本第1句]

[玩家朗读文本第2句]

[玩家朗读文本第3句]

[玩家朗读文本第4句（如有）]

## 背景

[可揭露信息：历史背景、居民行为、委托人过去，GM可自然透露]

## GM备注

[绝密信息：核心秘密真相、NPC隐藏动机，玩家主动发现才能揭露]
```

**示例**：

```markdown
# 导入

灰烬谷的长老玛莎来找你们，她胡须发灰，说话时不停地搓爪子

三天前那场大风把村外的古墓掀了，现在有群生面孔在那儿翻东西，昨晚路过还听见金属碰撞的声音

那些强盗已经挖开了好几座贵族墓，听说风暴女王的陪葬品还没被找到，求你们去阻止他们

她愿意付50皮普

## 背景

灰烬谷外的古墓是百年前为安葬风暴女王而建，守墓人一脉相传至今，玛莎的奶奶是最后一位守墓人。三天前的大风掀开了墓顶的石板，一群流浪鼠强盗趁夜潜入，已经挖开了外围几座贵族陪葬墓。上个月你们帮玛莎赶走过骚扰村庄的黄鼠狼，所以她这次来找你们。

## GM备注

强盗正在寻找主墓室，里面埋着风暴女王的权杖和一柄能召唤雷云的银剑。强盗头目独眼格里克是个前雇佣兵，手下有5到6只老鼠，他们打算在下一场风暴来临时动手，因为那时守墓咒语最弱。
```
