# 子模块：主题与场景生成器

## 功能

根据用户提供的关键词或随机掷骰，生成冒险地点的核心设定：名称、主题、历史、居民、秘密和氛围。

## 输入

- 主题关键词（可选）
- 房间数量范围（默认 5-8）
- 难度基调（轻松/标准/致命，默认标准）
- 已加载模块（如 WC-PACK）

如果已加载 WC-PACK，本子模块需要在建造类型掷骰之后追加一次 WC-1 微观地标掷骰。

掷骰请求：

```
WC-PACK 掷骰（已加载微观风味包）：
- 微观地标掷 d20
```

### 5. 确定第二派系

根据居民类型、居民目标与核心秘密，确定一个与居民对立或竞争的**第二派系**，让冒险地点内部形成冲突张力。

请用户掷 d6，用户回复数字后你在本表中查找对应结果并告知用户。

| d6 | 第二派系 |
| --- | --- |
| 1 | 守卫者：世代守护此处或核心秘密的忠实者，视居民为入侵者 |
| 2 | 竞争者：追寻与居民相同目标的对手（同一宝藏、同一法术、同一权力） |
| 3 | 天敌：以居民为猎物或仇敌的掠食者、宿敌 |
| 4 | 夺占者：想把居民赶出此处、霸占地盘的后来者 |

| 6 | 超自然存在：与核心秘密相关的幽灵、仙灵或魔法实体 |

**要求**：
- 第二派系必须与居民的目标或核心秘密存在冲突或竞争，形成两派在同一地点争夺或守护的张力
- 本步骤只确定第二派系的身份与立场，其生物类型与数据由遭遇与宝藏生成器（04）生成

### 7. 生成氛围基调

根据建造类型 + 衰败原因 + 居民类型的组合，推导出整体氛围。从以下基调中选择或组合：

- **压抑**：狭窄、封闭、空气沉重
- **诡异**：不该存在的东西出现在这里
- **荒凉**：空旷、寂静、曾经热闹如今死寂
- **危险**：掠食者的领地，处处是威胁的痕迹
- **神秘**：无法解释的现象，魔法残留
- **悲哀**：失去的东西仍然萦绕不去

### 8. 命名冒险地点

使用以下公式生成名称：

[氛围形容词] + 的 + [建造类型核心词]

或使用更诗意的命名方式。

### 9. 组合自检与矫正

所有要素确定后，主动审查组合是否合理，**禁止直接顺着明显冲突或不合理的结果继续生成**，避免返工。

**检查项**：

- 要素重复或同质：如第二派系与居民类型雷同（居民"幽灵"+第二派系"超自然存在"）、居民与核心秘密互相抵消
- 语义矛盾：衰败原因、居民、目标、秘密之间存在逻辑冲突且无法合理解释
- 组合生硬：多个要素拼凑感强，缺乏统一画面或明确的冲突张力
- 与用户提供的关键词明显不符

**矫正流程**：

- 发现冲突时，不重掷、不擅自替换，先向用户指出冲突点
- 提供 1-2 个矫正方案：调整某一项（如替换第二派系），或补充一段合理解释让组合自洽（如"洪水把村民困在塔顶，因此居民以塔楼为巢"）
- 用户确认后再继续后续步骤
