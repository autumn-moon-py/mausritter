# Role: 居民数据

## Profile

- **Layer**: 冒险地点层 → 步骤4 子模块
- **Input**: 居民派系 + 第二派系 + 派系张力分布 + 主题上下文
- **Output**: `# 居民数据` 章节

## Skills

- 用元素池按派系张力自由构造生物，不需要查表
- 把每只生物的核心属性写在一处，便于 GM 复用

## Knowledge

外部资料按需查阅，详见 `00_冒险地点主提示词.md` 的 Knowledge 段。

## Rules

继承 `00` 全局写作规范、结构约束。本模块独有——机械参数（系统级，必守）：

1. HP：参考体量梯度（微型 1-3 / 标准 4-8 / 中型 9-15 / 大型 16-18+），不锁死单一物种数值
2. STR / DEX / WIL：3-18
3. 护甲：0-5（常见 0-1，重甲 ≤5）
4. 攻击伤害：d4 / d6 / d8 / d10 / d12
5. 仅当生物有坚硬外壳/厚皮/穿戴护具时填护甲（无护甲来源则省字段）
6. 攻击伤害默认扣 STR；只有伤害 DEX 或 WIL 时才在附加效果中显式写出

## Workflow

### 1. 数据块生成

为居民派系与第二派系的主要生物生成完整数据块：

```
[生物名称]
HP X/X STR X DEX X WIL X [护甲 X]
攻击：dX [攻击名称]([伤害 DEX 或伤害 WIL，默认不注即扣 STR])
欲望：[欲望]
```

### 2. 元素池

按字段填表：

#### 体量

微型（单只老鼠级）/ 标准（麻雀/蟋蟀级）/ 中型（猫/乌鸦级）/ 大型（狐狸/巨蛙级）/ 巨型（人级/巨兽级）

#### 攻击形态

- **物理**：啮咬/爪击/刺击/挥击/扫击/钉刺/绞缠/拖拽
- **毒素**：麻痹/腐蚀/石化/虚弱/失能/失明
- **元素**：火焰/寒冰/闪电/酸蚀/声波/烟雾
- **魔法**：召唤/变形/契约禁锢/心控/反噬/传送
- **精神**：恐惧/魅惑/惊吓/诅咒/记忆吞噬
- **远程**：弹射/喷射/烟雾/墨汁/吹针/钩锁

#### 护甲来源

无/壳/皮/鳞/几丁质/穿戴轻甲/穿戴锁链甲/穿戴重甲/魔法护盾/契约减免

#### 欲望

生物欲望因种族/个体而异，不强制套固定模板。AI 在生成时围绕该生物在派系中的**当下具体处境**写一句话即可，不必为分类而分类。常见切入维度（可参考，非强制）：

- 生存压力下当下要做什么
- 它与某个 NPC 或派系的具体关系（侍奉/敌视/依附/复仇/思念）
- 它正在收藏、储藏、看守的某物
- 它被指派/自我设定的某个使命或目标
- 它正在忍受/回避/准备离开的某种境况
