# 子模块：可选模块 - 微观风味包（鼠怪复仇扩展）

## 模块说明

本模块来自《鼠怪的复仇》可借鉴扩展清单（v3）的世界构建类扩展 WC-1。

**加载方式**：在初始化阶段，由用户主动声明"启用微观风味包"才会加载。不启用时，主提示词和子模块按默认流程运行。

**模块内容**：
- WC-1 微观尺度地标表（d20，20条）

**默认行为**：当用户未声明启用时，所有掷骰按原表进行。当用户声明启用后，对应掷骰切换到本模块的表。

## 集成示例

启用微观风味包后，主题生成器流程变化：

**原流程**：掷 d20 决定建造类型 → 完成主题生成

**启用后流程**：掷 d20 决定建造类型 → 掷 WC-1 d20 决定微观地标 → 完成主题生成

最终输出的"建造类型"条目结合微观地标使用，例如：

- 建造类型 = 老鼠定居点 + 微观地标 = 火柴盒宫殿 → "老鼠定居点里有一座被人遗弃的火柴盒宫殿"
- 建造类型 = 巫师塔 + 微观地标 = 鹅卵石广场与苔藓花园 → "巫师塔周围是鼠民自建的鹅卵石广场"
