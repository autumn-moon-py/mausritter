# 子模块：主题与场景生成器

## 功能

根据用户提供的关键词或随机掷骰，生成冒险地点的核心设定：名称、主题、历史、居民、秘密和氛围。

## 输入

- 主题关键词（可选）
- 房间数量范围（默认 5-8）
- 难度基调（轻松/标准/致命，默认标准）

### 6. 生成氛围基调

根据建造类型 + 衰败原因 + 居民类型的组合，推导出整体氛围。从以下基调中选择或组合：

- **压抑**：狭窄、封闭、空气沉重
- **诡异**：不该存在的东西出现在这里
- **荒凉**：空旷、寂静、曾经热闹如今死寂
- **危险**：掠食者的领地，处处是威胁的痕迹
- **神秘**：无法解释的现象，魔法残留
- **悲哀**：失去的东西仍然萦绕不去

### 7. 命名冒险地点

使用以下公式生成名称：

[氛围形容词] + 的 + [建造类型核心词]

或使用更诗意的命名方式。

```markdown
## 主题与场景

**冒险地点**：[名称]
**一句话主题**：[一句话描述核心冲突或悬念]
**建造类型**：[类型]
**衰败原因**：[原因]
**居民**：[居民类型]，正在[目标]
**核心秘密**：[秘密]
**氛围基调**：[基调]
**建议房间数**：[数量]
```
