# 子模块：派系

## 功能

生成战役层的 3-4 个派系，含身份、目标、资源、进度标记与相互关系，让地图上的势力活起来。

## 输入

- 六角格地图与定居点
- 用户提供的现有冒险模组素材（可选）

## 处理流程

选择或创造 3-4 个派系作为六角格地图中的主要势力。派系是大型势力，不受玩家老鼠控制，它们帮助设定玩家选择的赌注，并创造游戏会话之外一个活生生世界的感觉。

**每个派系包含**：

- 名称与一句话身份
- 目标：正在试图完成的事，需要 2-5 个进度标记完成（取决于复杂程度）。目标应与其他派系互动或竞争相似资源
- 资源：反映派系在世界中的力量与影响力
- 与其他派系的关系

**素材来源**：

- 默认：从地图地标、定居点、区域主题推导生成
- 生物列表领主（猫领主、青蛙游侠骑士、猫头鹰巫师等，见 `../../生物列表.md` L11-24/L109-122/L180-193）是现成的强力派系原型，可直接选用或改编
- 若用户提供现有冒险模组：生成任务进行时按需从模组中提取居民/势力，提炼为跨地点的战役级派系（同一派系可横跨多个冒险地点，不是每个独立地点算一个派系），再补缺。素材不静态存放于生成器内部

**冲突要求**：派系目标必须互相竞争或冲突，形成战役张力。避免生成互不相干的独立派系。

**编写要求**：

- 派系目标具体可执行，禁止"想要和平"式空泛表述；目标用 ○ 标记进度（每个 ○ = 1 个进度标记，2-5 个，参照官方示例战役）
- 资源列出现实可感的力量（人力、武器、地盘、财宝、知识、人脉等）
- 关系列写明与哪些派系敌对、结盟或竞争，以及争的是什么

## 运行规则：派系推进（战役运行期）

生成派系后，以下规则随战役文档一并输出，指导 GM 在会话之间推进派系（参考主持人手册-完整版 L110-146）：

- 每个派系在会话之间推进其当前目标：掷 d6，该派系每有一个相关资源结果 +1；若目标针对某个对手派系，该对手每有一个相关资源结果 -1
- 最终结果 4-5：标记 1 个进度；6+：标记 2 个进度
- 派系完成一个目标时：增加一个新资源（代表增长的力量）；若该目标削弱了另一个派系，移除或改变其一个资源
- 派系推进或完成目标时，更新六角格地图显示力量消长，并将当前目标的暗示加入流言表

**玩家干预**：玩家帮助或干预派系目标时，标记或擦除 1-3 个进度（视干预规模）；玩家直接攻击并显著削弱某派系时，可移除或重写其一个资源。

## 输出格式

```markdown
# 派系

## [派系名]：[一句话身份]

资源：

[资源1]
[资源2]
...

目标：

○○○ [目标1]
○○○○○ [目标2]

关系：

[与谁敌对/结盟/竞争，争什么]

## [派系2名]：[一句话身份]
...
```
