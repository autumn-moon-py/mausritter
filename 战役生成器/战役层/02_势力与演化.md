# 子模块：势力与世界演化

## 功能

生成战役层的 3 个势力，含身份、动向与相互关系，并输出世界演化规则，让地图上的势力活起来而不需要账本。

## 输入

- 六角格地图与定居点
- 用户提供的现有冒险模组素材（可选）

## 处理流程

选择或创造 3 个势力作为六角格地图中的主要势力。势力是大型势力，不受玩家老鼠控制，它们帮助设定玩家选择的赌注，并创造游戏会话之外一个活生生世界的感觉。势力数以互不隶属的行动者计：主从、附庸、代理关系合并算一个，防止把同一阵营拆成多个势力凑数。

**每个势力包含**：

- 名称与一句话身份
- 动向：正在试图完成的事，具体可执行，禁止"想要和平"式空泛表述；不设进度标记、不记账
- 与其他势力的关系：写明与哪些势力敌对、结盟或竞争，以及争的是什么

**素材来源**：

- 默认：从地图地标、定居点、区域主题推导生成
- 生物列表领主（猫领主、青蛙游侠骑士、猫头鹰巫师等，见 `../../生物列表.md` L11-23/L109-121/L181-193）是现成的强力势力原型，可直接选用或改编
- 若用户提供现有冒险模组：生成任务进行时按需从模组中提取居民/势力，提炼为跨地点的战役级势力（同一势力可横跨多个冒险地点，不是每个独立地点算一个势力），再补缺。素材不静态存放于生成器内部

**冲突要求**：势力动向必须互相竞争或冲突，形成战役张力。避免生成互不相干的独立势力。

**家园安全**：势力动向作用于冒险地点与荒野层面，不得把定居点本身当作目标。镇上没有袭击、没有政治阴谋，玩家的休整据点永远安全。

## 演化规则（战役运行期）

势力不需要账本：没有资源、没有进度标记，两场游戏之间也不掷骰。以下规则由生成器在演化势力时遵循，不写入战役文档（参考 `../../西征指导手册.md` 幕间活动"时间持续流逝"L58-64）：

- 两次游戏之间默认流逝约一周（除非本场结果另有说明），世界按剧情逻辑演化，不掷骰
- 玩家离开的地点会变化：废墟可能重新涌入怪物，敌人重新集结或迁移，没做完的事继续发酵
- 玩家帮过或干预过的势力，按本场结果推进其动向；玩家没碰过的，倾向维持原状，只在有迹象时才变化
- 势力完成或放弃一个动向后，直接修改所有受影响的地点文件；同步改写受影响房间、内部遭遇和所有相关路径经过格子的内容，只保留修改后的最新内容（D-13）
- 已被摧毁、撤离、解决或不再存在的地点、房间、内部遭遇和路途遭遇直接删除，不保留旧内容供覆盖，也不建立初始/当前双层、roomId、实体索引、版本或状态覆盖层
- 玩家想自己建势力、盖建筑、当领袖时，说可以，让他们主动塑造世界

### 演化输入与输出

输入：战役文件、当前世界演化、当前势力动向、格网元数据.json、所有现存地点正文、本场带过记录和时间推进量。

处理顺序（D-13）：

1. 先从带过记录锁定玩家事实，以事实为准；已确认的完成、撤离、摧毁或失去不得被旧地点正文或旧演化文字覆盖。
2. 结合时间推进量与玩家事实，推演各势力当前目标，以及对据点的控制、重创、失去或瓦解；只写能影响地点或路途的变化。
3. 更新受影响地点、房间、内部遭遇、路途格子遭遇和世界演化；共享格子变化时同步所有相关路径，未受影响的地点不改写。
4. 直接删除已不存在的内容，不统计人数，不引入复杂状态层；告示板和世界任务只保留接口指导，不具体整理。

输出：更新后的势力动向与受影响地点文件。地点文件内直接写入最新地点状态、房间、内部遭遇和所有相关路径经过格子的逐格内容；若共享格子受影响，同步更新引用该格子的全部路径；未受影响的地点不改写（D-13）。

### 势力冲突三角形

- 2 个势力：二元对立过于扁平，缺少中间变量
- 4 个以上势力：GM 容易失控，世界变成泥潭

推荐 3 个势力形成三角形张力：每个势力至少与另外两个存在利益冲突或竞争，三角任意两边变化都让第三边被迫反应。势力动向必须互相竞争或冲突，禁止生成互不相干的独立势力。

## 输出格式

本节内容写入世界演化与冒险地点文件（`世界演化与冒险地点.md`，与战役主文件同目录，由战役主文件索引指向）：

```markdown
# 世界演化

[一句话叙事概览：势力互相咬合]

## [势力名]：[一句话身份]

动向：[动向1]；[动向2]；[动向3]。

[与谁敌对/结盟/竞争，争什么]

## [势力2名]：[一句话身份]
...
```
