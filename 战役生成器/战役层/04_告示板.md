# 子模块：告示板

## 功能

组装战役文档中的告示板章节。告示板只放条目本身，不写引导语、不写规则备注：世界任务条目可以贴在这里（条目格式由 `05_世界任务.md` 定义），但告示板只是世界任务的一个公开渠道；冒险地点NPC、路途NPC、势力行动或玩家已知事件也可以直接引出世界任务。地点的钩子收纳在冒险地点文件内部，告示板仅可选展示。

## 输入

- 可公开展示的世界任务条目（`05_世界任务.md` 产出，条目与详情对应）
- 冒险地点文件内部的钩子传闻（可选展示）

## 告示板定位

- 告示板章节只放条目本身，不写引导语、不写 GM 操作说明
- 需要公开招募或传播的世界任务条目贴告示板，详情见 `战役/世界任务/[任务名].md`（目录不存在时自动创建）；没有告示板条目的世界任务仍须保留详情文件，并写清其来源与触发入口
- 地点的钩子收纳在冒险地点文件内部（导入），GM 可把它贴到告示板或作为酒馆闲聊传闻散布，展示场景不限于告示板
- 告示板同时活跃的世界任务条目控制在3-5条，可含一条道德上不干净的任务；条目在任务过期、完成或被势力动向改变后更新或撤下。此数量只统计告示板条目，不限制由NPC或事件引出的未公开任务
- 告示板条目不展开冒险地点或世界任务的内部细节

## 地点的钩子（可选展示）

钩子本体写在冒险地点文件内部（导入/传闻），格式见冒险地点层 `02_导入与背景生成器.md`。告示板若要展示某地点钩子，从对应冒险地点文件取用，不改写、不增删字段。

## 世界任务条目

条目格式由 `05_世界任务.md` 定义（标题/来源/任务/完成/奖励 + 详情指向），此处不重复；告示板只引用生成好的条目。

## 输出格式

```markdown
# 告示板

## 世界任务

### [标题]
来源：[词汇]
任务：[...]
完成：[...]
奖励：[...]
> 详情：[见 战役/世界任务/[任务名].md]
```
