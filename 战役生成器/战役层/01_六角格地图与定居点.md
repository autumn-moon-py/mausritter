# 子模块：六角格地图与定居点

## 功能

生成战役层的六角格地图（5×5，中心友好定居点）与定居点设定。

## 输入

- 战役主题或区域关键词（可选，提供时围绕关键词挑选而非纯掷骰）
- 定居点规模掷骰（可选）

## 处理流程

### 2. 生成定居点

定居点是地图中心与玩家大本营，是补给、流言与委托的来源。

| --- | --- |

## 输出格式

```markdown
# 六角格地图

1：[地标名]
[类型与细节合成的一行描述]

2：[地标名]
[类型与细节合成的一行描述]

...

中心：[定居点名称]
[一句话概况]

# 定居点

[名称与规模][治理方式]
[习俗/显著特征/产业]
[酒馆/客栈]
```

**风格**：六角格用"编号：地标名 + 多行描述"列表式（参照官方示例战役），每格描述为类型、地标、细节合成的一句话，可读且不雷同。

## 可选：生成 Hexfriend 地图文件

六角格地图确定后，可调用 `Hexfriend/tools/cli.mjs` 将地图可视化为 .hexfriend 文件（在 Hexfriend 中打开可查看与编辑）。

**产出物**：`[战役名].hexfriend` 文件 + 对应的描述 JSON（每格含 col/row、terrain 地形 key、label 地标名、detail 细节）。

**地形 key 映射**（来自战役层六角格类型表）：

| 六角格类型 | terrain key |
| --- | --- |
| 乡村 | farmland / grassland |
| 森林 | forest |
| 河流 | river |
| 人类城镇 | town / city |
| 定居点（中心） | settlement |
| 其他（按需） | plains/hills/mountains/marsh/cave/ruin/graveyard/water 等，用 `node cli.mjs --list-terrain` 查看全部 |

**调用方式**：

```bash
node Hexfriend/tools/cli.mjs 地图描述.json -o 地图.hexfriend
```

**描述 JSON 格式**：

```json
{
  "title": "秋烬河谷",
  "orientation": "flatTop",
  "shape": "square",
  "rows": 5,
  "columns": 5,
  "hexes": [
    { "col": 0, "row": 0, "terrain": "forest", "label": "蜂巢", "detail": "银光蜂巢" }
  ]
}
```

- shape 可选 square（行列）或 flower（hexesOut 半径），与战役地图布局一致
- col/row 从 0 开始，与六角格编号对应（编号1 = col0,row0）
- terrain 用上表映射，label 为地标名（居中大字），detail 为细节（小字）
- 也可用 `cat 描述.json | node cli.mjs - -o 地图.hexfriend` 走 stdin

**接入说明**：作为可选项，GM 需要可视化地图时再生成；纯文本战役文档仍按上文输出格式。
