# 子模块：世界任务

## 功能

生成世界任务：由告示板、冒险地点中的NPC、路途遭遇中的NPC、势力行动或玩家已知事件引出的战役级活动。任务来源可以有固定出现位置，但任务的目标、发展与后果不必绑定单一地图格；任务可在来源处直接接取，也可在后续合适的场景中触发。世界任务类似最小的冒险地点，有具体的场景、角色与结局，但体量小于冒险地点（通常单场可完成）。世界任务详情由战役层直接产出（00 层级边界声明的例外：战役层唯一可产出最小冒险级内容的地方），写成独立详情文件，存入 `战役/世界任务/[任务名].md`（目录不存在时自动创建）。告示板只是可选的公开渠道，不是世界任务的必要组成；有告示板条目的任务，详情文件与条目对应。

## 与冒险地点的区别

- 冒险地点：地图上固定的格子，玩家主动前往，有房间布局、居民数据、遭遇表
- 世界任务：来源和起点可以固定在某个NPC或事件，目标、发展与后果不必固定在单一格子；可以通过告示板、交谈、路途偶遇、冒险地点内的行动或世界演化触发；只含一到两个场景、少量角色与一次小遭遇，单场可完成

## 输入

- 世界演化中的势力动向（世界任务与活世界呼应，会随时间演化）
- 可转化为任务的世界素材：告示板条目、冒险地点导入或NPC诉求、路途遭遇中的NPC与事件、势力动向、玩家已知的未完成事项
- 可选的用户钩子或既有任务要求

## 处理流程

1. 识别任务来源与入口：注明任务来自告示板、固定地点NPC、路途NPC、势力行动、玩家已知事件或纯异象；来源是世界事实，不等于玩家已经知道任务
2. 写详情文件：给 GM 的具体内容，类似最小冒险地点；若来源是冒险地点或路途NPC，只使用已公开的身份、诉求与可观察事实，不把无关的地点内部秘密搬入战役层
3. 决定公开渠道：需要时才写告示板条目；没有告示板条目的任务，保留在详情文件并写清触发入口
4. 定数量与生命周期：活跃任务按全部入口合计控制在可管理范围，告示板仅统计其中实际张贴的条目，随任务过期、完成或被势力动向改变而更新或撤下

## 告示板条目格式

```markdown
### [标题]

来源：[词汇，如 悬赏通告/固定地点NPC/路途NPC/势力行动/酒馆赌约/匿名字条；没有公开来源时写明未知或省略]
任务：[相对客观的任务详情；允许是夸大、误导或过时的传闻]
完成：[完成标准，叙述性，无冗余废话]
奖励：[报酬，叙述性]
> 详情：[见 战役/世界任务/[任务名].md]
```

## 详情文件格式（类似最小冒险地点）

```markdown
# [任务名]

[一句话任务简介]

# 来源与触发

[任务从哪里或由什么事件引出：若来源是冒险地点或路途NPC，可写来源文件与NPC身份；只写玩家可获得的来源信息，不展开无关地点内部细节]

[何时触发与现场条件：写来源处的接触条件、可复用的环境或路途情境；不把任务目标强行绑定到单一地图格]

# 公开与真相

[条目在告示板上说的（公开）与实际情况（真相）的偏差：夸大、误导或过时的部分是什么；纯异象任务可省略此节]

# 场景

[触发后的场景描述：玩家看到什么、听到什么]

## [关键角色]

[角色/生物：是谁、想要什么、知道什么，含 HP/STR/DEX/WIL 与攻击（按生物列表）]

# 发展

[任务如何推进：线索、小谜题或小遭遇、可能的分支]

# 结局与奖励

[可能的结局与奖励，叙述性；任务如何收尾]

# 演化

[玩家不理会时，任务会怎样变化]
```

## 西征特性（打破 AI 标准式）

- 多样式：悬赏、委托、异象、赌约、交易、契约、诅咒、谜团换着来，不要全是同一结构
- 可缺省：有的任务没有来源（纯异象，无人张贴）、有的没有完成标准（开放结局）、有的没有明确奖励（人情、秘密、未知）；有的任务是夸大、误导或过时的传闻，详情注明公开部分与真相的偏差
- 无主线：任务来自世界活动、势力动向、NPC诉求或玩家已知事件，不是 GM强塞的主线；玩家追不追、怎么追完全自定
- 多入口：告示板只是公开渠道之一；任务也可以由冒险地点NPC、路途NPC、势力代理或事件现场发布
- 起点与目标分离：来源可以位于固定地点，但任务的目标、发展与后果不必绑定该地点；需要固定地点作为起点时，在来源与触发中明确，不把它伪装成随机偶遇
- 有代价：奖励揭示委托人的地位、恐惧或绝望；报酬过高必有隐情
- 会演化：任务会过期、会因势力动向变化；告示板上可以有一条道德上不干净的任务
- 来源可信度：一句话通告说清公开部分，真实动机留在 GM 笔记

### 设计保险

- **三条线索**：每个核心结论至少三条独立路径通向。玩家错过两条还能从第三条推出；任何依赖单一发现的谜都会因一次坏骰而卡死
- **完成边界**：要么明示条件，要么留开放空间，不混着用；混用会让玩家不知道算不算完成
