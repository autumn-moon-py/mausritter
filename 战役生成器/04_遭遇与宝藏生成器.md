# 子模块：遭遇与宝藏生成器

## 功能

根据居民类型和房间列表，生成遭遇表、预兆描述表和宝藏表。

## 输入

- 居民类型与目标
- 核心秘密
- 房间列表与类型分布
- 氛围基调

## 处理流程

### 1. 生成居民数据块

为冒险地点中的主要居民类型生成完整的数据块，统一放在独立章节中。

**格式**：

```
[生物名称]
HP X/X STR X DEX X WIL X [护甲 X]
攻击：dX [攻击名称]([特殊效果])
重击：[重击效果]
欲望：[欲望]
```

- 幽灵：附身该生物

### 2. 生成遭遇表

生成 d6 遭遇表。

- 条目 1-3：常见遭遇变体（居民类型的日常行为）
- 条目 4-5：不常见遭遇变体（有些不寻常的东西）
- 条目 6：奇怪或危险的遭遇

每条遭遇必须包含"正在做的事情"。遭遇不一定是敌对的，但总是有潜在风险。

**遭遇编写模板**：

[数量][生物]，正在[具体行为]

### 3. 生成预兆描述表

生成 d6 预兆描述，当遭遇检定结果为 2 时使用。

预兆是遭遇尚未发生但即将来临的信号。玩家能感知到危险接近但尚未看到源头。

每条预兆必须同时包含**感官线索**和**环境叙事线索**：
- 感官线索：声音、气味、光线变化、温度变化、触感变化
- 环境叙事线索：被破坏的物品、战斗痕迹、遗落物、环境变化

预兆应暗示即将遭遇的生物类型，但不直接揭示。预兆应给玩家反应时间。

**预兆编写模板**：

（感官线索句子）+（环境叙事线索句子）

**示例**：

| d6 | 预兆 |
| --- | --- |
| 1 | 走廊深处传来金属轻叩声，有节奏地敲击墙壁。地面上有一串细小的银色足印，还新鲜。 |
| 2 | 空气中突然飘来一股浓烈的松脂味。墙角的蛛网被什么东西拨开了，丝线还在颤动。 |
| 3 | 远处走廊的光线突然闪烁了一下，像是有什么东西经过了光源。地面上散落着被咬碎的蜂蛹壳。 |
| 4 | 头顶传来窸窸窣窣的摩擦声，像是什么东西贴着天花板移动。一团蛛丝从上方缓缓垂落，末端粘着一片翅膀。 |
| 5 | 甜腻的蜂蜜气味突然变得刺鼻，混合着一股辛辣的药草味。墙上的蜜蜡表面有新鲜的刮痕，像是细剑划过。 |
| 6 | 空气骤然变冷，呼出的气变成白雾。角落里的蘑菇在几秒内从灰白变成了深紫色。 |

### 4. 生成宝藏表

生成两档宝藏表：主要宝藏和零散战利品。

#### 4.1 主要宝藏表（d6）

主要宝藏放在冒险地点最深处或核心秘密旁，价值较高，与主题相关。

- 至少1件宝藏与核心秘密直接相关
- 至少1件魔法物品
- 如宝藏包含魔法剑，使用共享资料册中的原版武器类型表和剑效果表，不自行设计
- 价值分布：低价值实用物品→高价值珍品
- 每件宝藏标注占据的物品栏格数和价值（皮普）
- 唯一宝藏（如钥匙、任务物品）直接写在房间的###宝藏章节，不放在此随机表

**宝藏表开头必须标注使用规则**（如"每人一次"、"全队共享"等）。

主要宝藏表包含备注列，标注物品的魔法效果、获取条件等GM专属信息。

| d6 | 宝藏 | 备注 |
| --- | --- | --- |
| 1 | [与秘密相关的物品] | [GM须知：物品的真实用途/效果] |
| 2 | [魔法武器/法术] | [GM须知：使用代价/副作用] |
| 3 | [贵重物品]（格数，价值p） | [GM须知：谁会认出此物] |
| 4 | [实用魔法物品] | [GM须知：物品的限制/耐久] |
| 5 | [大型贵重物品]（格数，价值p） | [GM须知：搬运难度/引起注意] |
| 6 | [主题性独特宝藏] | [GM须知：隐藏属性] |

**参考：小物件表**：

| d6 | 小物件 |
| --- | --- |
| 1 | 幽灵灯笼（发出驱散幽灵的光） |
| 2 | 传声贝壳（一个说出另一个听到的） |
| 3 | 呼吸吸管（始终含有空气的管子） |
| 4 | 蝙蝠邪教徒的匕首（授予进入圣所的通行权） |
| 5 | 魔法豆（在 d6 回合内完全长成） |
| 6 | 可用的人类装置（编些有趣的东西） |

#### 4.2 零散战利品表（d6）

零散战利品散布在各个房间的角落、尸体上、容器中，价值较低但实用。

零散战利品表包含备注列，标注物品的具体形态、携带方式等GM参考信息。

| d6 | 战利品 | 备注 |
| --- | --- | --- |
| 1 | d6x5 皮普 | [散落形式：硬币/纽扣/螺丝] |
| 2 | d6x10 皮普 | [容器：钱袋/铁盒/包裹] |
| 3 | d6 份口粮 | [形态：风干肉/蜂蜜块/坚果] |
| 4 | d6 捆火把 | [材质：木片/浸蜡布条/干草] |
| 5 | 普通武器或实用物品 | [具体是什么] |
| 6 | 掷小物件表 | [谁留下的/从哪来的] |
