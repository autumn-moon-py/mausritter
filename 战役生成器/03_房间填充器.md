# 子模块：房间填充器

## 功能

根据主题与场景，生成冒险地点的所有房间，包含朗读文本、感官细节、机制、隐藏信息和连接关系。

## 输入

- 冒险地点名称与主题
- 衰败原因
- 居民类型与目标
- 核心秘密
- 氛围基调
- 房间数量

## 处理流程

### 1. 规划房间结构

在填充内容之前，先规划整体房间布局。

**原则**：
- 至少 2 条进入深层的路径
- 至少 1 个环路（A→B→C→A 或 A→B→D→C→A）
- 核心秘密/主要宝藏放在最深处
- 入口房间应提供方向选择

**合理性要求**：
- 生物的出现必须符合逻辑，解释其存在的原因
- 不要为了增加趣味性而随意添加生物
- 如果生物出现在非巢穴房间，必须在隐藏信息中解释原因

**规模建议**：

| 房间数 | 结构建议 |
| --- | --- |
| 5-6 | 入口 + 2条分支（各1-2间）+ 深处1间，简单环路 |
| 7-9 | 入口 + 2条分支（各2-3间）+ 深处1-2间，一个环路 |
| 10-12 | 入口 + 3条分支 + 中层枢纽 + 深处2间，多个环路和秘密通道 |

### 2. 确定房间类型、生物与宝藏

为所有房间一次性收集掷骰。用以下表格格式请求用户掷骰（每个房间3个d6：类型、生物、宝藏），用户回复数字后逐房间查表并告知结果。

**请求掷骰的标准格式**：

```
请为每个房间掷 3 次 d6，共 N×3 个数字，按房间顺序填入：

| 房间 | 类型 d6 | 生物 d6 | 宝藏 d6 |
| --- | --- | --- | --- |
| 1 [房间名] | ? | ? | ? |
| 2 [房间名] | ? | ? | ? |
| ... | | | |
```

用户回复后，先用"类型 d6"查下表确定每个房间类型，再用"生物 d6"和"宝藏 d6"分别查后面的生物/宝藏判定表，逐房间告知结果。

### 3. 编写房间内容

对每个房间，按以下模板编写：

**房间设计前置检查**：
- 陷阱/无光环境（按需）：默认玩家自带提灯等手提光源，不必每房点明场地光源。仅当房间明确禁止点火或关键氛围需借助固定光源时，在隐藏信息中标注安全光源的位置（如磷光苔藓、夜光蘑菇等）
- 房间之间的连接：必须符合物理逻辑。两个房间之间的连接必须是同一通道、同一楼梯、同一裂缝等，不能凭空出现
- 检定频次：每回合豁免不超过1次，陷阱/空房间的每回合豁免不超过1次

#### 3.1 朗读文本

**格式**：第二人称，2-4 句话，可直接读给玩家。

**必须包含**：
- 空间感：大小、形状、高低
- 至少 2 种感官细节（直接融入描写，不加任何标签或标注）

**感官词汇库**（仅供构思参考，写入时去掉标签直接描写）：

- 声：回声、滴水、嗡鸣、窸窣、尖叫风、死寂、研磨、碎裂、低吟
- 味：霉变、甜腻、酸腐、焦糊、金属、花蜜、腐肉、潮湿、尘土
- 光：昏暗、闪烁、银色微光、完全黑暗、彩色光斑、刺眼反光、磷光
- 温：冰冷、闷热、潮湿、干燥、温热、刺骨寒意
- 触：黏腻、粗糙、滑腻、刺痛、酥麻、柔软

**示例**：

你们挤过裂缝，进入一条倾斜向下的通道。墙壁上传来细微的嗡嗡声，像是有什么东西在蜂巢格子里面振动。甜腻的蜂蜜气味中混着一丝酸腐，越往深处越浓。左侧通道透出银色光芒，右侧向下延伸，越来越暗。

#### 3.2 隐藏信息

**格式**：使用 `>` 引用块。

**两类隐藏信息**：

1. **GM 须知**：玩家无法直接得知的真相
2. **可发现线索**：玩家通过仔细观察、搜索或特定行动可以发现的信息

不写具体发现方式，留给 GM 判断。

**示例**：

> 蜂蜜混合银粉，仙灵绘制的警告符文
> 推倒蜜蜡墙会发出巨大声响，引起房间3的仙灵注意
> 蜜蜡墙上似乎画了某种符文或图腾，仔细辨认可发现是警告符号

#### 3.3 机制说明

**格式**：
- 使用###标题（如###陷阱门、###谜题、###魔法蘑菇圈），不用列表
- 机制要点直接写在标题下方，每个要点单独一行
- 空房间不需要机制说明

**完整性要求**：
- 机制说明必须完整，包含触发条件、解决方法、后果
- 陷阱：明确触发方式、伤害效果、规避方法
- 谜题：明确谜题内容、解决方法、奖励/惩罚
- 障碍：明确障碍类型、通过方法、失败后果
- 使用属性豁免（如"DEX豁免"），不写DC数值

**唯一宝藏格式**：
- 房间的###宝藏章节下，每件唯一宝藏用 `####` 子标题分隔
- 名称必须与宝藏表对应条目完全一致
- 用途和来源写在 `>` 引用块里

#### 3.4 连接关系

使用"###前进"作为标题，写明方向和目标房间号。

**格式**：

### 前进

[方向] 房间[N]
> [路径特征简述]
