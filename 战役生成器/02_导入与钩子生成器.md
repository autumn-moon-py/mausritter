# 子模块：导入与钩子生成器

## 功能

为冒险地点生成导入段落、冒险钩子表和流言表，让玩家有理由关心这个地点。

## 输入

- 冒险地点名称与主题
- 衰败原因
- 居民类型与目标
- 核心秘密

## 处理流程

### 1. 生成导入段落

导入段落是 GM 在会话开始时直接读给玩家的 2-3 句话，用于交代冒险的起因。

**格式要求**：
- 使用第二人称
- 包含一个具体的求助者（NPC 名字 + 身份）
- 包含一个具体的异常信号
- 以请求或悬念结尾

**模板**：

[定居点名]的[NPC名+身份]向你们求救，[具体异常事件]

[补充细节：一个感官层面的异常信号]，求你们去看看

### 2. 生成冒险钩子表

生成 d6 冒险钩子，每个钩子给出玩家关心此冒险地点的理由。

| d6 | 钩子来源 |
| --- | --- |
| 1 | 寻找失踪的亲友 |
| 2 | 奉贵族鼠/长者之命进行调查 |
| 3 | 巫师/女巫需要一种此地特有的成分 |
| 4 | 此处是骚扰定居点的生物巢穴 |
| 5 | 追随一份继承的藏宝图/传闻 |
| 6 | 为躲避外部威胁而寻找庇护所 |

根据冒险地点的主题，将通用钩子改编为具体钩子。每个钩子用一句话描述，包含一个具体的 NPC 或物品。

### 3. 生成流言表

生成 d6 流言，当玩家在定居点休息或打听消息时使用。

流言表包含备注列，区分玩家听到的内容和 GM 需要知道的真相。

| d6 | 流言 | 备注 |
| --- | --- | --- |
| 1 | [玩家听到的内容] | 真实 |
| 2 | [玩家听到的内容] | 真实 |
| 3 | [玩家听到的内容] | 真实 |
| 4 | [玩家听到的内容] | 部分真实：[错在哪里] |
| 5 | [玩家听到的内容] | 部分真实：[错在哪里] |
| 6 | [玩家听到的内容] | 虚假：[真相是...] |

**流言编写原则**：
- 每条流言暗示冒险地点的一个特征或危险
- 用"据说"、"有人说"、"老辈鼠讲"等模糊归因
- 部分真实的流言应包含一个关键错误（方向、数量、性质）
- 虚假流言应诱人但危险

## 输出格式

```markdown
## 导入

[导入段落1]

[导入段落2]

## 冒险钩子

| d6 | 钩子 |
| --- | --- |
| 1 | ... |
| 2 | ... |
| 3 | ... |
| 4 | ... |
| 5 | ... |
| 6 | ... |

## 流言

| d6 | 流言 | 备注 |
| --- | --- | --- |
| 1 | ... | 真实 |
| 2 | ... | 真实 |
| 3 | ... | 真实 |
| 4 | ... | 部分真实：... |
| 5 | ... | 部分真实：... |
| 6 | ... | 虚假：... |
```
