# 烛泉墓地

内战让老鼠的祖先安息之地沦为废墟，如今被魔法扭曲的老鼠聚集在这里

他们搜刮皮普，抓活老鼠进坟当苦力，谁也说不清那成堆的钱最终流向了哪里

# 导入

约定的小酒馆门口，一只剃光了毛的老鼠迎上来，自称秃毛，说从烛泉墓地一路跑来找你们

他两只耳朵冻得发紫，站着都在打瞌睡，说话时爪子一直绞着破斗篷的边，像随时会栽倒在地上

他说墓地里那群老鼠最近疯了，把活老鼠往坟里拖。他的养兄弟，一只右耳缺了一角的灰鼠

被关在地底当苦力，求你们去看看，他从怀里掏出所有积蓄，300皮普，攒了半辈子的家当

## 背景

百年前，烛泉墓地是老鼠贵族与长老的安葬之地，墓穴以蜡烛为灯，蜡油常年堆成墙

五十年前，守墓鼠族为争夺墓产继承权打了一场内战，自相残杀，死者被草草埋进自己守护的墓室

幸存者离散，墓地就此荒废。战争的裂痕与坍塌至今横在墓道之间

如今墓地里住着一伙被魔法改变的老鼠，自称烛泉的守夜人，四处强征老鼠进墓挖坟找皮普

谁交得少，谁就被关进墓室底层。墓门口那座蜡烛头熔成的喷泉日夜燃着，是守夜人的地标

秃毛是被这群老鼠养大的孤儿之一，从小在墓道里长大，剃光的毛皮是劳动鼠的标记

剃毛是为了防跳蚤，方便在墓穴里钻行。前阵子守夜人开始抓墓外的活老鼠充数

他的养兄弟被拖进地底。秃毛趁夜逃出墓地，一路打听才找到你们

最近守夜人收皮普收得越来越急，墓地里已经传出反抗者被打死的风声

## GM备注

大约一年前，墓地深处的旧祭坛被雷雨劈开，露出一道通往仙灵领域的裂隙

裂隙另一头的仙灵是一个高阶法师级的灵体，痴迷皮普，守夜人头目是最早接触传送门的老鼠

被仙灵的微光改变最深，收来的皮普大多被投进裂隙，被仙灵收走，私心重的守夜人会偷偷扣下一点

## 1 袜中管道

你们扒开灌木，土坡边躺着一只褪色的灰袜子，袜口朝上
> 袜子是人类晾晒时被风刮落的

土坡那头的墓门口，一座蜡烛头熔成的喷泉日夜燃着，火舌在凝固的蜡层上跳动
> 喷泉的火是内战前守墓长老点燃的永恒烛，仙灵能量渗入后烧不灭，守夜人视之为圣物

隔着老远都能闻到融蜡的气味，是整片荒墓最醒目的地标

顺着袜筒往里爬，尽头是一段向上倾斜的管道，内壁是融过又凝固的蜡
> 蜡是古代葬礼时滴落的烛油，这条通道曾是墓地的正式入口之一

管道尽头是坟丘顶的洞口，一只皮毛泛光的瘦老鼠蹲在洞口边
> 守夜人哨兵，向每个进入者收10皮普，交不出就拖去当苦力；肯交钱的外来者一律放行

洞口边往下看，石阶没入黑暗

## 6 通电铜板室
> 零散战利品

下行的墓道走到底是一间铺满铜板的墓室，铜板中央立着一座蜡台
> 铜板是人类旧地窖的加热板，被搬进墓室当祭台底座

台上放着一件发亮的东西。墓室只有铜板缝里偶尔跳起电弧，嘶一声又没了
> 电流来自传送门的能量渗漏，沿着地下的旧电线传导到这里

一股说不清的刺鼻香气弥漫着，越靠近蜡台，铜板上的蓝光越亮
> 刺鼻香气是残留的人类香水瓶与仙灵能量的混合物

### 通电铜板地板

铜板地板带电，踩上去需DEX豁免，失败受电击伤

干燥绝缘物垫脚可安全通过,潮湿的爪子更危险

摸清地下旧电线的走向，拔掉或切断电源或关闭传送门

## 7 传送门前营地
> 主要宝藏/零散战利品

半开的石门后是一个大墓室，地上散落着毯子和空罐，墙角锁着两只瘦骨嶙峋的老鼠
> 苦力老鼠，其中一只身上带旧伤，是之前反抗守夜人的老鼠，被抓来了房间7

一只皮毛泛光的老鼠蹲在裂隙前，把皮普一枚枚丢进去
> 守夜人头目，被仙灵微光改变最深，守在裂隙旁寸步不离

### 仙灵交易

把皮普投进裂隙，仙灵会以低语回应，一次投入至少10p，投进去的皮普被吞没消失

仙灵是高阶法师级的灵体，能力有限。玩家自由说出愿望，GM按换算表估价，仙灵按价收取皮普

蜡封仙币是仙灵认可的硬通货，一枚可抵任意一次交易

摇响仙灵银铃可让仙灵现身回应，持续1回合，交易期间不受仙灵微光幻觉影响

仙灵只收皮普，强夺裂隙里的东西会被拒绝，动静会引来守夜人注意

| 愿望难度 | 效果范围 | 估价 |
| - | - | - |
| 小愿 | 一次性小效果：点火、照明、传讯、告知一件秘密 | d6×10p |
| 中愿 | 持续或强力效果：治疗、睡眠、解除普通诅咒 | d6×50p |
| 大愿 | 永久或重大效果：解除强力诅咒、永久祝福 | d6×100p以上 |
| 拒绝 | 复活死者、凭空造物造钱、改变心智与爱情、跨界传送 | 拒绝或报天价 |

### 仙灵微光幻觉

靠近裂隙1格以内需WIL豁免，失败陷入幻觉

幻觉期间每回合可再豁免挣脱或被外力叫醒
