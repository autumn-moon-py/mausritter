# 秋烬河谷

秋日的河谷丘陵，古墓、漂移学院与银光蜂巢之间，四股势力彼此咬合。柳树渡的老鼠夹在中间，谁也不知道这场秋风会把哪一边的坟头先吹塌。

# 六角格地图

1：蜂巢
密林深处挂着一只老大的蜂巢，银光从巢口漏出来，采蜜鼠救回来了却仍绕着巢口的银光绕道走，不敢再进去。

2：花田
一片菊花田，田埂上插着稻草人，花心里全是蜜蜂，空气甜得发腻。

3：古橡树上的面孔
老橡树树干上鼓起一张脸，眼窝处滴着树液，路过时总觉得它在看你。

4：麦田
收割后的麦田，茬子扎脚，几捆麦秆还码在田埂上没搬走。

5：荒废农舍
农舍塌了半边屋顶，门板被拆去当柴烧，屋里落了层灰，灶台上有半个新鲜爪印。

6：柳林河湾
河流拐弯处柳条垂进水里，湾里漂着落叶和一根断绳，绳头系着个空笼子。

7：鼠匪藏身处
林缘一间堆满干草的窝棚，门口有车轮印，窝棚里码着偷来的粮食口袋。

8：空心树桩
一棵空心大树的桩子，里面铺着干草，像是有谁住过，树皮上刻着记号。

9：明亮林间空地
阳光漏进的一片空地，地上蘑菇成圈长着，圈内草色格外绿。

10：偏移学院
林间一座歪斜的石头建筑，墙皮一会儿消失一会儿出现，走近能闻到旧书灰味。

11：石墙
一段塌了半截的石头墙，墙根堆着干蘑菇，墙缝里塞着几枚锈钉子。

12：柳树渡（定居点）
见定居点一节。

13：河上倒木桥
一棵倒下的树横在河上当桥，树皮被踩得溜光，桥下水声很急。

14：白蚁蛀蚀的大树
一棵被白蚁蛀空的大树，树洞里堆着啃剩的果核，洞壁有拖行的黏液痕。

15：兔穴
一片兔子窝，土堆上净是新鲜的爪印，兔子探头探脑，见了人不躲。

16：烛泉墓地
山坡上一片烛火点点的古墓，墓门立着蜡烛头熔成的喷泉，夜里能听见挖土声。

17：牛骨架
草地上横着一具牛骨架，肋骨间钻进几丛野花，骨架里挂着风干的鸟巢。

18：层叠瀑布
溪流从三层石台跌下，水花溅在石头上，瀑布后面隐约有个黑洞洞的口子。

19：石环
一圈立起的石头，环心长着反季节的绿草，风到这里就停了。

20：风暴女王陵寝
风暴掀开顶的古墓群，石缝里长满湿苔，安魂歌已经停了好些日子，墓门被人从外面用石头堵上了。

21：病窟
河岸斜坡上一个狐狸挖的洞口，洞边散着碎药瓶玻璃，空气里有化学苦味。洞口堆着新翻的土，有人往里面送过东西。

22：芦苇浅滩
一片芦苇浅滩，苇秆在风里弯腰，浅水里有鱼翻身的水花。

23：废弃汽车
一辆锈透的汽车斜在路边，车门大开，座位被老鼠啃出絮，车底有个黑乎乎的大洞。

24：排水管口
路边一根水泥管口，管口磨得发亮，管道深处传来滴水声和细碎脚步。

25：柴棚
路边一间柴棚，木柴码得整整齐齐，棚里堆着几袋谷子，袋口系着红绳。

# 定居点

柳树渡，小村，约百来只老鼠，由市议员会议治理。这里是玩家的大本营，永远安全，镇上没有战斗与阴谋。

居民酿造蜂蜜酒，用刺鼻的草药调味，村口隔老远就能闻到。木桥连接河两岸，桥头晾着草药，是村里唯一的产业。村口立着一块任务板，钉着来往商队、失踪老鼠和远方奇事的告示，想找线索的老鼠都先来看一眼。

酒馆叫弯曲奶酪，招牌菜是厚切河鱼排，二楼通铺便宜，是探险者歇脚的地方。

## 派系运行规则

每场游戏结束后为每个派系掷d6，该派系每有一个相关资源结果加1；目标针对对手派系时，对手每有一个相关资源结果减1。最终4-5标记1个进度，6及以上标记2个进度。派系完成目标时增加一个新资源；若该目标削弱了对手，移除或改变对手一个资源。玩家帮助或干预时，标记或擦除1-3个进度；玩家直接重创某派系时，可移除或重写其一个资源。

已带过地点随派系推进和时间流逝发生变化：派系的目标落在那里的，地点重新活跃，可二次探查。GM在玩家再次前往前，用派系进度和当前季节更新该地点的现状。

# 运行说明

柳树渡是玩家唯一的安全家园，每场游戏从柳树渡出发，也在柳树渡结束。没有固定队伍，谁有空谁来，玩家自己决定这趟去哪。

- 出发前，玩家从任务板、酒馆流言和上次游戏的结果里挑目标，GM可随时准备任意地点，不限定一场一个
- 已带过的地点不消失，世界随时间变化，随时可能被重新探查（派系推进、季节事件会改写地点的现状）
- 每场游戏结束后，由GM记录世界状态，更新共享地图与任务板
- 派系在每场游戏后推进一次，具体见派系运行规则
